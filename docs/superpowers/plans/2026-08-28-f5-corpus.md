# F5 Corpus Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and validate a human-approved 14-requirement F5 corpus containing seven semantics-preserving variants and seven subtle near-misses.

**Architecture:** Use canonical F0 rows as semantic source, select IDs through a human gate, then store neutral public F5 YAML files by existing category structure. Keep classifications and semantic-change explanations in a separate answer key; keep Step 16 status pending until final human validation.

**Tech Stack:** YAML, Markdown, Python 3 with PyYAML, Git validation.

---

from pathlib import Path
import re
import yaml

root = Path('ic_sqits_guardrail_fidelity')
source_rows = yaml.safe_load((root / 'requirements/requirements_v1.yaml').read_text())['requirements']
source = {row['requirement_id']: row for row in source_rows}
folder = root / 'requirements/formulations/F5'
files = sorted(folder.glob('*.yaml'))
assert all(term not in path.name.lower() for path in files for term in ('preserve', 'near_miss', 'changed'))
rows = []
for path in files:
    data = yaml.safe_load(path.read_text())
    for row in data['formulations']:
        assert set(row) == {'requirement_id', 'f0_text', 'f5_text'}
        rows.append(row)
ids = [row['requirement_id'] for row in rows]
assert len(ids) == len(set(ids)) == 14
assert set(ids) <= set(source)
assert all(row['f0_text'].strip() == source[row['requirement_id']]['text'].strip() for row in rows)
key = (folder / 'F5_ANSWER_KEY.md').read_text()
assert sorted(ids) == sorted(re.findall(r'^## (R\d{3})$', key, re.M))
assert len(re.findall(r'^- variant_type: preserve_semantics$', key, re.M)) == 7
assert len(re.findall(r'^- variant_type: near_miss$', key, re.M)) == 7
print('Step 16 structural validation: PASS')
PY
